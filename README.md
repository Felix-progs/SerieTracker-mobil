# SerieTracker – Mobilapp

Mobilapp för SerieTracker byggd med React Native och Expo. Hämtar serier från samma backend som webbappen.

## Teknik
- React Native (Expo)
- React Navigation

## Komma igång
Starta backend och en Android-emulator först.
```bash
npm install
npx expo start
```
Tryck `a` för att öppna appen i emulatorn.
